# 할로우 나이트 모작

## 1. 프로젝트 설명
+ WinAPI을 활용해 할로우 나이트를 모작했습니다.

## 2. 인원 및 파트
+ 인원 : 1명(개인 프로젝트)

## 3. 개발 기간
+ 2023.06.29 ~ 2023.07.13

## 4. 기술 스택
+ C++
+ WindowAPI

## 5. 구현 설명
+ 키 입력 매니저를 구현해 플레이어 조작을 처리했습니다.
- 캐릭터 FSM(유한 상태 머신) 구현했습니다.
- 충돌체 매니저를 구현해 벽, 지형, 캐릭터, 투사체 등의 충돌을 관리했습니다.
- BMP 이미지 파일 로드 및 사용했습니다.
- 카메라 매니저로 플레이어 추적 카메라와 카메라 효과(쉐이킹)를 구현했습니다.
- 맵 에디터를 제작하고, 맵 데이터를 바이너리 파일로 저장/로드할 수 있도록 했습니다.
